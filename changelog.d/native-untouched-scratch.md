fix: **Smaller Widget memory on Windows**: each Widget process drops from about 11.4 MiB to 9.2 MiB private working set. The pinned Native SDK no longer makes ~2 MiB of fixed-capacity scratch resident before a Widget uses it: stack frames from capture and chrome paths that a live Widget never runs, per-frame display-list scratch on the stack, and default images of effect and scroll-extent tables.
