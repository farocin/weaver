Base `shadow-none`, `rounded-[0px]`, and text shadows no longer count. Children of leaves now count only toward a separate `RetainedWidgetNodeLimit` (the runtime tree's `max_nodes`), not toward Native nodes. On 25 boundary cases check's verdict now matches whether the runtime renders; before, it matched on 15.
